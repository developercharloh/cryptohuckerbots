---
name: VIXUS brand style
description: The product's approved visible brand spelling and compatibility boundary for technical identifiers.
---

The user-facing product name is `VIXUS`, always written in uppercase. This applies to UI copy, emails, page metadata, installed-app labels, tutorial text, support messages, and authenticator issuers.

**Why:** The user explicitly chose the uppercase name while keeping existing URLs, package names, route paths, asset filenames, and other technical identifiers stable.

**How to apply:** Write new visible copy as `VIXUS`. Do not rename `vixus-ai` technical identifiers unless a deliberate compatibility migration is planned.
